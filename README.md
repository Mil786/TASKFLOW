# TaskFlow

Um gerenciador de tarefas moderno e responsivo desenvolvido com HTML, CSS e JavaScript puro.

O projeto foi criado como parte da minha evolução no desenvolvimento web, com foco em praticar JavaScript, manipulação do DOM, armazenamento local e criação de interfaces responsivas.

---

## 🚀 Demonstração

> https://mil786.github.io/TASKFLOW/ 

---

## 📌 Sobre o projeto

O TaskFlow é uma aplicação web para gerenciamento de tarefas.

A proposta é permitir que o usuário organize suas atividades de forma simples, acompanhe seu progresso e mantenha suas tarefas salvas mesmo após fechar o navegador.

O projeto foi desenvolvido utilizando apenas tecnologias nativas da web, sem frameworks ou bibliotecas externas.

## 🛠️ Tecnologias utilizadas

### HTML5

Utilizado para:

- Layout responsivo
- Flexbox

- Animações e transições
- Dark Mode
- Responsividade para dispositivos móveis

### JavaScript

Utilizado para:

- Manipulação do DOM
- Eventos
- Criação dinâmica de elementos
- Filtros

- Atualização dinâmica das estatísticas
